# StiliyanEnchev.github.io

Personal portfolio and online resume website.

🌐 **Live:** https://stiliyanenchev.github.io/

## Technologies

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## Run Locally

Clone the repository:

```bash
git clone https://github.com/StiliyanEnchev/StiliyanEnchev.github.io.git
```

Open the project folder and launch `index.html` in your browser.

You can also use VS Code with the **Live Server** extension.

## Deployment

The website is hosted with GitHub Pages from the `main` branch.

After making changes:

```bash
git add .
git commit -m "Update website"
git push origin main
```

GitHub Pages will automatically update the live website.

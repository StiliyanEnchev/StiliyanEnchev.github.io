## 🚀 Run Locally

This is a static website and does not require any package installation, build tools, or backend.

### Clone the repository

```bash
git clone https://github.com/StiliyanEnchev/StiliyanEnchev.github.io.git
```

### Open the project

```bash
cd StiliyanEnchev.github.io
```

### Launch locally

Open `index.html` directly in your web browser.

Alternatively, you can use the **Live Server** extension in Visual Studio Code for a local development server.

## 🌐 GitHub Pages

The website is hosted using **GitHub Pages**.

Because this is a user GitHub Pages repository named:

```text
StiliyanEnchev.github.io
```

the website is available at:

```text
https://stiliyanenchev.github.io/
```

### Deployment

The website is deployed from the `main` branch.

To configure GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch.
6. Select `/ (root)` as the folder.
7. Click **Save**.

GitHub Pages will publish the contents of the selected branch automatically.

## 🔄 Update the Website

After making changes locally:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

GitHub Pages will automatically deploy the changes from the `main` branch.
